# Super Bowl Commerical ASC Studio

## How to Get Started

- Install `uv` Python package manager
  - For Linux/Mac users run this command:
    - ```curl -LsSf https://astral.sh/uv/install.sh | sh```
  - For Windows users, run **ONE** of these commands:
    - ```powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex```
    - ```winget install --id=astral-sh.uv -e```

- Setup your environment
  - Run this command first:
    - ```uv sync```

- Enjoy exploring the Super Bowl Commercial Data with either `polars` or `pandas` as your primary tool!
